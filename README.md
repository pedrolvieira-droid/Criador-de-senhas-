# Criador-de-senhas-
O foco aqui não é apenas o código final, mas o **processo de melhoria contínua**. Eu começo com um script extremamente básico e, a cada atualização, aplico "novos" conceitos fundamentais da programação para elevar a qualidade da senha gerada com base em dados recolhidos do usuario.
o objetivo é testar os fundamentos de lógica de programação desde de códigos mais simplórios, até um nível mais avançado
